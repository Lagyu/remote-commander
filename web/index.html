CONNECTION GUIDE

From local computer to remote workspace

01

Build the agent

In the project directory, build the Rust agent on macOS or Linux.

cargo build --release -p rdc-agent
02

Pair your computer

Run locally, then verify and approve the displayed pairing code in this workspace.

03

Choose a folder

Start with read access. Add --allow-write for file changes or --allow-shell for shell access.

./target/release/remote-commander run --root /path/to/project

Connect a Streamable HTTP MCP client using OAuth. Shell access runs as the local operating-system user; the selected folder does not sandbox shell commands.
